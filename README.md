# Training_Work — Painel Administrativo

Sistema de gestão de treinamentos e CRM administrativo.

## 🚀 Como Rodar

1. Clone o repositório.
2. Instale as dependências: `npm install`
3. Configure o Firebase no arquivo `js/modules/firebase-config.js` (ou via `.env`).
4. Inicie o servidor local: `npm run dev` (ou use o Live Server do VS Code).
5. Acesse: `http://localhost:5501/admin/login.html`
